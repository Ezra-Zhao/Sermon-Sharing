# Sermon-Sharing

讲道稿分享。每周一篇，旧稿也排好队慢慢往前发。

Weekly sermon manuscripts, shared for learning and ministry. New and archived manuscripts, released one a week.

## 每篇格式

- **主题** — 一句话讲清这篇道讲什么
- **经文** — 主要经文出处
- **大纲** — 分段小标题
- **全文** — 完整讲道稿
- **场合与日期** — 在哪里讲的（可不填）
